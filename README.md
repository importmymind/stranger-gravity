# Stranger Gravity 🚲

Stranger Gravity is a high-octane, endless runner web game inspired by the **Stranger Things** universe. Built using vanilla JavaScript and HTML5 Canvas, the game challenges players to navigate through the Hawkins suburbs and the dark "Upside Down" dimension by manipulating gravity.

## 🎮 Game Mechanics

In this world, the floor is just a suggestion. Players must switch between top and bottom platforms to avoid deadly obstacles and collect items.

- **Gravity Flip:** A single click or spacebar press flips your character’s gravity instantly.
- **Dynamic Dimensions:** Encounter portals that transport you to the **Upside Down**, where visuals change and danger increases.
- **Procedural Level Generation:** Every run is unique! The game dynamically generates:
    - **Floating Islands:** High-altitude platforms requiring precise timing.
    - **Stair Patterns:** Consecutive steps that test your reflexes.
    - **Squeeze Points:** Tight corridors that demand focus.
    - **Trap Gaps:** Sudden breaks in the floor or ceiling.

## ✨ Features

- **Character Selection:** Choose your favorite character from the Hawkins gang (Mike, Will, Eleven, Dustin, Lucas, Max). Each character has a unique sprite.
- **Waffle Collection:** Collect **Eggo Waffles** to increase your score and climb the leaderboards.
- **Persistent High Scores:** Your "Best Score" is saved locally in your browser so you can always try to beat your personal record.
- **Authentic Soundtrack:** Immersive 80s synth-wave background music and sound effects.
- **Retro UI:** A menu system inspired by the iconic "Alphabet Wall" from the series.

## 🕹️ Controls

- **Spacebar / Left Click:** Flip Gravity
- **Keyboard Shortcuts (Menu):**
    - `M`: Mike | `W`: Will | `E`: Eleven | `D`: Dustin | `L`: Lucas | `X`: Max

## 🛠️ Technical Overview
**Engine:** Pure Vanilla JavaScript (No external game engines).

**Rendering:** HTML5 Canvas API for high-performance 2D graphics.

**Styling:** Tailwind CSS for a modern, responsive UI overlay.

**Optimization:** Object pooling logic and precise collision detection for smooth gameplay.
